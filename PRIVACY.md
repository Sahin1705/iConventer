# Privacy Policy for iConverter

**Last updated:** October 10, 2026

Şahin Dağlı ("we", "our", or "developer") developed **iConverter** as a Free, open-source utility application. This page informs users regarding our policies regarding the collection, use, and disclosure of personal data when using the iConverter application.

---

### 1. No Data Collection (Zero Telemetry)
iConverter is designed with a strict **Privacy-First** architecture:
- **No Personal Data Collected:** We do not collect, store, transmit, or share any personal information, device identifiers, IP addresses, or conversion activity.
- **100% On-Device Local Processing:** All media conversions (videos, photos, audios) are executed completely offline on your Mac using native macOS hardware acceleration (Apple VideoToolbox, ImageIO).
- **No Cloud Uploads:** Your files are never uploaded to any remote server or cloud service.
- **No Third-Party Analytics / Advertising:** iConverter does not include any third-party tracking SDKs, analytics frameworks, or advertising libraries.

---

### 2. File Access Permissions
iConverter operates within Apple's App Sandbox. The application only accesses files and directories that you explicitly select via:
- Drag and drop into the application window
- The macOS file picker dialog (`NSOpenPanel`)
- The macOS Finder Quick Action context menu

File access is strictly temporary and used solely for reading the input media and saving the converted file to your specified destination folder.
